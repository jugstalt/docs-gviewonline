    Transform¶

    Aggregate¶

    Combines all items into a single item with lists. Attachments are not carried over.

    Inputs: main · Outputs: main

    Parameter Type Description
    Aggregate
    mode    		 one of: allItemData, individualFields What to collect from the items.
    allItemData: One list with all items, e.g. to send them in one request.
    individualFields: One list per field with the values of all items, e.g. all email addresses.
    Default: allItemData.
    Put into field
    destination    		 text Name of the field that gets the list, e.g. orders. Only when Aggregate is allItemData.
    Fields
    fields    		 list of text Fields to collect, e.g. email or customer.name; items without the field are left out. Only when Aggregate is individualFields.
    Example: All items into one list

    Three items become one item with a list, e.g. to send all orders in one HTTP request.

    Parameters:

    {
  "mode": "allItemData",
  "destination": "orders"
}

    Input:

    [
  {
    "id": 1,
    "amount": 120
  },
  {
    "id": 2,
    "amount": 80
  },
  {
    "id": 3,
    "amount": 45
  }
]

    Output:

    [
  {
    "orders": [
      {
        "id": 1,
        "amount": 120
      },
      {
        "id": 2,
        "amount": 80
      },
      {
        "id": 3,
        "amount": 45
      }
    ]
  }
]
    Example: Collect the values of one field

    One list per field, e.g. all addresses for one mail. Items without the field are left out.

    Parameters:

    {
  "mode": "individualFields",
  "fields": [
    "email"
  ]
}

    Input:

    [
  {
    "name": "Anna",
    "email": "anna@example.com"
  },
  {
    "name": "Ben"
  },
  {
    "name": "Cleo",
    "email": "cleo@example.com"
  }
]

    Output:

    [
  {
    "email": [
      "anna@example.com",
      "cleo@example.com"
    ]
  }
]

    Code¶

    Transforms items with JavaScript, once for all items or once per item.

    Inputs: main · Outputs: main

    Parameter Type Description
    Mode
    mode    		 one of: allItems, eachItem How often the code runs.
    allItems: Runs once: items holds all input items, return an array of objects.
    eachItem: Runs per item with $json: return an object, or null to drop the item.
    Default: allItems.
    JavaScript
    code    		 code Available: items (once for all), $json, $itemIndex (per item), $input, $node, $workflow, $execution, $now. Source code; {{ }} is not evaluated.
    Example: Sum up all items

    Once for all items: items holds the JSON of every item; the returned array becomes the output items.

    Parameters:

    {
  "mode": "allItems",
  "code": "const total = items.reduce((sum, item) => sum + item.amount, 0);\nreturn [{ count: items.length, total }];"
}

    Input:

    [
  {
    "id": 1,
    "amount": 120
  },
  {
    "id": 2,
    "amount": 80
  }
]

    Output:

    [
  {
    "count": 2,
    "total": 200
  }
]
    Example: Change each item, drop some

    Once per item: $json is the item; return null to drop it.

    Parameters:

    {
  "mode": "eachItem",
  "code": "if ($json.amount < 50) return null;\nreturn { ...$json, customer: $json.customer.toUpperCase() };"
}

    Input:

    [
  {
    "customer": "Anna",
    "amount": 120
  },
  {
    "customer": "Ben",
    "amount": 30
  }
]

    Output:

    [
  {
    "customer": "ANNA",
    "amount": 120
  }
]

    Crypto¶

    Hashes text or attachments (SHA-256, SHA-512, SHA-1, MD5), signs them with HMAC, creates UUIDs and encodes or decodes Base64. Writes the result into a field of each item.

    Inputs: main · Outputs: main

    Parameter Type Description
    Operation
    operation    		 one of: hash, hmac, uuid, base64Encode, base64Decode What to compute.
    hash: A checksum of text or a file, e.g. to detect changes.
    hmac: A signature with a secret key, e.g. to check or sign webhook calls.
    uuid: A new random id, e.g. 3f2b8c1e-….
    base64Encode: Text or a file as Base64 text.
    base64Decode: Base64 text back to plain text.
    Default: hash.
    Source
    source    		 one of: value, binary Work on the text in Value or on an attachment.
    value: The text in Value.
    binary: The content of an attachment, e.g. a file from Read File.
    Only when Operation is hash or hmac or base64Encode. Default: value.
    Value
    value    		 text Text to work on, e.g. {{ $json.body }}; ignored for an attachment. Only when Operation is hash or hmac or base64Encode or base64Decode. Supports expressions.
    Attachment name
    binaryProperty    		 text Name of the attachment, data unless an earlier node named it differently. Only when Source is binary.
    Algorithm
    algorithm    		 one of: sha256, sha512, sha1, md5 Hash function; SHA-256 unless a partner asks for another.
    sha256: The common choice.
    sha512: Longer and stronger.
    sha1: Only for checksums of old systems, not for security.
    md5: Only for checksums of old systems, not for security.
    Only when Operation is hash or hmac. Default: sha256.
    Secret
    secret    		 text The key, best from a secret variable, e.g. {{ $vars.WEBHOOK_SECRET }}. Only when Operation is hmac. Supports expressions.
    Output
    output    		 one of: hex, base64 How the result is written.
    hex: Lower-case hex digits, e.g. 2cf24d….
    base64: Base64 text, shorter.
    Only when Operation is hash or hmac. Default: hex.
    Target field (required)
    targetField    		 text Field that gets the result, e.g. hash or signature.
    Example: SHA-256 checksum of a field

    The item keeps its fields and gets the checksum, e.g. to notice when a text has changed.

    Parameters:

    {
  "operation": "hash",
  "value": "{{ $json.text }}",
  "targetField": "hash"
}

    Input:

    [
  {
    "text": "hello"
  }
]

    Output:

    [
  {
    "text": "hello",
    "hash": "2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824"
  }
]
    Example: Encode text as Base64

    Parameters:

    {
  "operation": "base64Encode",
  "value": "{{ $json.user }}:{{ $json.password }}",
  "targetField": "basic"
}

    Input:

    [
  {
    "user": "pipe",
    "password": "secret"
  }
]

    Output:

    [
  {
    "user": "pipe",
    "password": "secret",
    "basic": "cGlwZTpzZWNyZXQ="
  }
]
    Example: A new id per item

    Every item gets its own random UUID.

    Parameters:

    {
  "operation": "uuid",
  "targetField": "id"
}

    Input:

    [
  {
    "customer": "Anna"
  }
]

    Output:

    [
  {
    "customer": "Anna",
    "id": "3f2b8c1e-5d47-4f0a-9b8e-2c6a1d7e4f90"
  }
]

    Date & Time¶

    Gets the current time, formats, parses and calculates dates, and converts between time zones. Writes the result into a field of each item.

    Inputs: main · Outputs: main

    Parameter Type Description
    Operation
    operation    		 one of: now, format, parse, add, subtract, difference, convertTimeZone, startOf What to do with the date.
    now: The current date and time.
    format: A date as text in a pattern, e.g. 02.11.2026.
    parse: Text in a pattern to a date (ISO 8601).
    add: A date plus an amount of time, e.g. 14 days.
    subtract: A date minus an amount of time.
    difference: The time between two dates, in a unit.
    convertTimeZone: The same moment in another time zone.
    startOf: The start of the day, week, month … of a date.
    Default: format.
    Date
    value    		 text The date: ISO 8601 like 2026-11-02T08:30:00+01:00, Unix seconds or milliseconds, or for Parse text in the pattern. Only when Operation is format or parse or add or subtract or difference or convertTimeZone or startOf. Supports expressions.
    Until
    until    		 text The second date; empty means now. The result is positive when it is later than Date. Only when Operation is difference. Supports expressions.
    Pattern
    pattern    		 text e.g. dd.MM.yyyy or yyyy-MM-dd HH:mm; empty: ISO 8601 (Format) or any common form (Parse). Only when Operation is format or parse. Supports expressions.
    Culture
    culture    		 text Language of month and day names, e.g. de-DE or en-US. Only when Operation is format or parse. In Advanced. Supports expressions.
    Amount
    amount    		 number How many units, e.g. 14. Only when Operation is add or subtract. Default: 1.
    Unit
    unit    		 one of: milliseconds, seconds, minutes, hours, days, weeks, months, years Unit of the amount, the difference or the start.
    milliseconds: 1/1000 second.
    seconds: Seconds.
    minutes: Minutes.
    hours: Hours.
    days: Calendar days.
    weeks: 7 days; a week starts on Monday.
    months: Calendar months, whole numbers only.
    years: Calendar years, whole numbers only.
    Only when Operation is add or subtract or difference or startOf. Default: days.
    Time zone
    timeZone    		 text e.g. Europe/Vienna; Convert time zone: the target, Parse: the zone of text without offset, otherwise the zone to work in. Only when Operation is now or format or parse or convertTimeZone or startOf. Supports expressions.
    Target field (required)
    targetField    		 text Field for the result, e.g. date or meta.due.
    Example: Due date 14 days after the invoice date

    Parameters:

    {
  "operation": "add",
  "value": "{{ $json.invoiceDate }}",
  "amount": 14,
  "unit": "days",
  "targetField": "dueDate"
}

    Input:

    [
  {
    "invoice": "R-17",
    "invoiceDate": "2026-11-02T08:30:00+01:00"
  }
]

    Output:

    [
  {
    "invoice": "R-17",
    "invoiceDate": "2026-11-02T08:30:00+01:00",
    "dueDate": "2026-11-16T08:30:00+01:00"
  }
]
    Example: Format a date for people

    Parameters:

    {
  "operation": "format",
  "value": "{{ $json.invoiceDate }}",
  "pattern": "dd.MM.yyyy",
  "targetField": "printed"
}

    Input:

    [
  {
    "invoiceDate": "2026-11-02T08:30:00+01:00"
  }
]

    Output:

    [
  {
    "invoiceDate": "2026-11-02T08:30:00+01:00",
    "printed": "02.11.2026"
  }
]
    Example: Days between two dates

    Parameters:

    {
  "operation": "difference",
  "value": "{{ $json.openedAt }}",
  "until": "{{ $json.closedAt }}",
  "unit": "days",
  "targetField": "days"
}

    Input:

    [
  {
    "ticket": 4711,
    "openedAt": "2026-11-02T00:00:00Z",
    "closedAt": "2026-11-05T12:00:00Z"
  }
]

    Output:

    [
  {
    "ticket": 4711,
    "openedAt": "2026-11-02T00:00:00Z",
    "closedAt": "2026-11-05T12:00:00Z",
    "days": 3.5
  }
]

    Limit¶

    Keeps only the first or the last N items.

    Inputs: main · Outputs: main

    Parameter Type Description
    Max items
    maxItems    		 integer How many items go on, e.g. 10; the rest is dropped. Default: 1.
    Keep
    keep    		 one of: firstItems, lastItems Which items are kept.
    firstItems: The items at the start, e.g. the newest after sorting by date descending.
    lastItems: The items at the end.
    Default: firstItems.
    Example: Keep the first two items

    E.g. after Sort: only the top two go on.

    Parameters:

    {
  "maxItems": 2,
  "keep": "firstItems"
}

    Input:

    [
  {
    "product": "Lamp",
    "sold": 42
  },
  {
    "product": "Desk",
    "sold": 17
  },
  {
    "product": "Chair",
    "sold": 9
  }
]

    Output:

    [
  {
    "product": "Lamp",
    "sold": 42
  },
  {
    "product": "Desk",
    "sold": 17
  }
]

    Remove Duplicates¶

    Keeps the first of several equal items (all fields equal, or the selected fields).

    Inputs: main · Outputs: main

    Parameter Type Description
    Compare
    compare    		 one of: allFields, selectedFields When two items count as the same.
    allFields: Items are duplicates when all their fields are equal.
    selectedFields: Items are duplicates when the fields below are equal, e.g. the same email.
    Default: allFields.
    Fields
    fields    		 list of text Fields that together identify an item, e.g. email or customer.id. Only when Compare is selectedFields.
    Example: One item per email address

    The first item of each address is kept, later ones are dropped.

    Parameters:

    {
  "compare": "selectedFields",
  "fields": [
    "email"
  ]
}

    Input:

    [
  {
    "email": "anna@example.com",
    "source": "web"
  },
  {
    "email": "ben@example.com",
    "source": "web"
  },
  {
    "email": "anna@example.com",
    "source": "fair"
  }
]

    Output:

    [
  {
    "email": "anna@example.com",
    "source": "web"
  },
  {
    "email": "ben@example.com",
    "source": "web"
  }
]

    Set¶

    Sets, renames or keeps fields of each item.

    Inputs: main · Outputs: main

    Parameter Type Description
    Fields
    fields    		 key/value pairs Field (e.g. address.city) → value, e.g. Vienna or {{ $json.price * 1.2 }}.
    Rename
    rename    		 key/value pairs Old field → new name, e.g. mail → email; done before the fields are set.
    Keep only set fields
    keepOnlySet    		 true/false Drop all other fields: the items have only the fields set above. Default: false.
    Example: Add a calculated field and rename one

    Values may be fixed or expressions; numbers stay numbers. Rename happens before the fields are set.

    Parameters:

    {
  "fields": {
    "gross": "{{ $json.net * 1.2 }}",
    "currency": "EUR"
  },
  "rename": {
    "mail": "email"
  }
}

    Input:

    [
  {
    "customer": "Anna",
    "mail": "anna@example.com",
    "net": 100
  }
]

    Output:

    [
  {
    "customer": "Anna",
    "net": 100,
    "email": "anna@example.com",
    "gross": 120,
    "currency": "EUR"
  }
]
    Example: Keep only some fields

    With 'Keep only set fields' everything else is dropped, e.g. before writing a CSV file.

    Parameters:

    {
  "fields": {
    "name": "{{ $json.customer.name }}",
    "city": "{{ $json.customer.address.city }}"
  },
  "keepOnlySet": true
}

    Input:

    [
  {
    "id": 7,
    "customer": {
      "name": "Anna",
      "address": {
        "city": "Graz",
        "zip": "8010"
      }
    }
  }
]

    Output:

    [
  {
    "name": "Anna",
    "city": "Graz"
  }
]

    Sort¶

    Sorts the items by one or more fields: numbers by value, text alphabetically, missing values last.

    Inputs: main · Outputs: main

    Parameter Type Description
    Sort by
    fields    		 list of text Fields in order of priority, e.g. customer, then date desc; desc sorts from high to low.
    Example: Highest amount first

    Numbers are compared as numbers, so 120 comes before 80.

    Parameters:

    {
  "fields": [
    "amount desc"
  ]
}

    Input:

    [
  {
    "customer": "Ben",
    "amount": 80
  },
  {
    "customer": "Anna",
    "amount": 120
  },
  {
    "customer": "Cleo",
    "amount": 45
  }
]

    Output:

    [
  {
    "customer": "Anna",
    "amount": 120
  },
  {
    "customer": "Ben",
    "amount": 80
  },
  {
    "customer": "Cleo",
    "amount": 45
  }
]

    Split in Batches¶

    Turns the items into one item per batch: batch (from 1), batches, count and the items as a list. Attachments are not carried over.

    Inputs: main · Outputs: main

    Parameter Type Description
    Batch size
    batchSize    		 integer Items per batch, e.g. 100; the last batch may have fewer. Default: 10.
    Put into field
    destination    		 text Name of the field that holds the items of a batch, e.g. items.
    Example: Batches of two

    Five items become three batches, e.g. to call Execute Workflow or an API with at most two items at a time.

    Parameters:

    {
  "batchSize": 2
}

    Input:

    [
  {
    "id": 1
  },
  {
    "id": 2
  },
  {
    "id": 3
  },
  {
    "id": 4
  },
  {
    "id": 5
  }
]

    Output:

    [
  {
    "batch": 1,
    "batches": 3,
    "count": 2,
    "items": [
      {
        "id": 1
      },
      {
        "id": 2
      }
    ]
  },
  {
    "batch": 2,
    "batches": 3,
    "count": 2,
    "items": [
      {
        "id": 3
      },
      {
        "id": 4
      }
    ]
  },
  {
    "batch": 3,
    "batches": 3,
    "count": 1,
    "items": [
      {
        "id": 5
      }
    ]
  }
]

    Split Out¶

    Turns a list in a field into one item per element.

    Inputs: main · Outputs: main

    Parameter Type Description
    Field to split out (required)
    field    		 text A field with a list, e.g. orders or customer.addresses; every element becomes an item.
    Keep the other fields of the item
    includeOtherFields    		 true/false Copy the other fields into every new item, e.g. the customer to each of their orders. Default: false.
    Example: One item per order line

    The list lines becomes two items; with 'Keep the other fields' each line also gets the order number.

    Parameters:

    {
  "field": "lines",
  "includeOtherFields": true
}

    Input:

    [
  {
    "order": "A-17",
    "lines": [
      {
        "sku": "P-1",
        "qty": 2
      },
      {
        "sku": "P-7",
        "qty": 1
      }
    ]
  }
]

    Output:

    [
  {
    "order": "A-17",
    "sku": "P-1",
    "qty": 2
  },
  {
    "order": "A-17",
    "sku": "P-7",
    "qty": 1
  }
]
    Example: A list of plain values

    Values that aren't objects keep the name of the field.

    Parameters:

    {
  "field": "tags"
}

    Input:

    [
  {
    "id": 1,
    "tags": [
      "urgent",
      "billing"
    ]
  }
]

    Output:

    [
  {
    "tags": "urgent"
  },
  {
    "tags": "billing"
  }
]
